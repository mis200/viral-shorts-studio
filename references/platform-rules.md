# 主流短视频平台规则速查

> 算法会变，发布前以平台最新规则为准。以下为通用速记。

## 快手
- 调性：老铁、真实、接地气、信任感
- 时长：15-60s 为主，口播 / 实录吃香
- 发布：晚 18-22 点、周末上午
- 强项：挂车转化、直播、私域（需合规）
- 雷区：过度精致、说教感

## 抖音
- 调性：强网感、节奏快、完播率优先
- 时长：7-15s 黄金，信息密度高
- 发布：工作日晚 19-22 点，周五六更晚
- 强项：爆款投流、星图商单
- 雷区：搬运、低质、硬广限流

## 视频号
- 调性：熟人+公域、中老年、干货 / 情感 / 正能量
- 时长：30-60s 适中
- 发布：早 8-9、午 12、晚 20-21
- 强项：转发裂变、公众号联动
- 雷区：过度营销、标题党

## 小红书
- 调性：姐妹感、封面党、种草、搜索流量
- 形式：图文 + 短视频均可，封面决定点击
- 发布：早 8、午 12、晚 20-23
- 强项：搜索长尾、品牌种草
- 雷区：硬广、医美功效词
