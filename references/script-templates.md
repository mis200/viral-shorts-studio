# 短视频脚本模板（五段式）

> 结构：钩子 → 痛点 → 方案 → 信任 → 行动。全程标注 `[画面]`、`口播` 与时长。一个视频只讲一个卖点。

## 模板A：种草带货型（适合快手 / 抖音挂车）
```
[0-3s 画面] 手持产品特写 / 使用前后对比
口播（钩子）：<钩子，前3秒>
[3-10s 画面] 使用场景演示
口播（痛点）：<共鸣痛点>
[10-25s 画面] 核心卖点拆解（1个就够）
口播（方案）：<为什么好>
[25-35s 画面] 真实体验 / 数据
口播（信任）：<证据：实测 / 评价 / 对比>
[35-45s 画面] 指向购物车
口播（行动）：<限时 / 限量 / 点击购物车>
```

## 模板B：口播知识型（适合视频号 / 小红书涨粉）
```
[0-3s] 钩子
[3-40s] 一个干货点讲透（分 2-3 个小点）
[40-50s] 总结金句 + 引导关注 / 收藏
```

## 模板C：剧情反转型（适合抖音涨粉）
```
[0-3s] 冲突开场
[3-20s] 铺垫误会
[20-30s] 反转揭秘
[30-40s] 价值升华 + 引导互动
```
