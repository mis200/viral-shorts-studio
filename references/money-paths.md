# 4 条变现路径

> 按用户目标匹配 1-2 条，给首步动作。变现的前提是内容垂直 + 稳定更新，别一上来就想着收割。

## 1. 短视频带货（挂车 / 橱窗）
- 适合：有货源 / 无货源（精选联盟、快手小店、抖音橱窗）
- 首步：开通商品橱窗 → 选 1 个高佣金低客单品 → 用种草模板拍 3 条测款
- 关键指标：完播率 + 点击购物车率

## 2. 私域引流（微信 / 社群）
- 适合：高客单、复购、服务类（咨询、课程、定制）
- 首步：主页留钩子（资料 / 福利）→ 合规引导私信 → 进群承接
- 注意：平台对站外引流有限制，用"主页 / 评论"合规话术，避免直接曝微信

## 3. 商单 / 接广（星图 / 快接单 / 蒲公英）
- 适合：已有一批粉丝（通常 1000+）
- 首步：入驻平台接单渠道 → 保持垂直内容 → 报价 ≈ 粉丝数 × 单价
- 关键：内容真实不翻车，保留案例作品集

## 4. 知识付费 / 课程
- 适合：专业能力（育儿 / 理财 / 技能 / 职场）
- 首步：用知识型模板做免费干货引流 → 小偿试听 → 正价课
- 关键：人设信任 + 交付感

## 起步建议（0 粉也能做）
先做"带货 + 商单"组合：无货源挂车跑量，同时沉淀垂直内容等商单。别一上来就砸钱投流。
