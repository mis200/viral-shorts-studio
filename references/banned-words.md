# 短视频常见违禁词 / 敏感词（务必扫描）

> 不同平台细则不同，以下为通用高危词。发布前用 `scripts/check_banned.py` 扫描全部文案。广告法对"绝对化用语"处罚极重，宁可换说法也不要赌。

## 绝对化用语（广告法高危）
最、第一、唯一、顶级、国家级、世界级、极致、绝无仅有、史无前例、万能、100%、绝对、独家、首发、首次、全网最低、销量第一、领导者、创始、世界领先

## 虚假 / 夸大承诺
保证赚钱、稳赚、躺赚、一夜暴富、100%有效、 guaranteed、包治、根治、永不反弹

## 医疗 / 功效暗示（无资质禁用）
治疗、治愈、消炎、抗癌、排毒、减肥特效、丰胸、增高、处方

## 平台违禁营销词
加微信（引导私域需合规）、加我、私聊、代购、刷单、刷量、搬运

## 色情 / 暴力 / 迷信
算命、改运、招财、风水改命、鬼神、血腥、暴力、色情暗示

## 政治 / 社会敏感
涉及时政、灾难消费、性别对立、地域黑等一律规避，按各平台实时规则执行。

> 提示：抖音 / 快手对"最 / 第一"等绝对化用语处罚极重，建议用"很 / 超 / 多数"等相对表述替代。
