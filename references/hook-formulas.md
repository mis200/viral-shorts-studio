# 5 类爆款钩子公式

> 钩子必须落在前 3 秒。每条视频选 1 个主钩子 + 可选 1 个副钩子。钩子的目的是让人停下滑动、生出"然后呢？"的冲动。

## 1. 悬念 / 反直觉
公式："你以为 X，其实 Y" / "90% 的人都做错了"
示例："你以为快手只能刷着玩？有人靠它月入 5 万"

## 2. 痛点直击
公式："是不是……（共鸣场景）"
示例："是不是每次拍视频都没人看？不是你丑，是你开头错了"

## 3. 利益前置
公式："3 个动作 / 1 个方法，让你……"
示例："1 个方法，让你的视频完播率翻 3 倍"

## 4. 身份代入
公式："XX 的人注意了 / 如果你……"
示例："想在家带娃还能赚钱的宝妈，这条一定要看完"

## 5. 冲突 / 反差
公式："别再 X 了，改成 Y" / "我劝你别……"
示例："别再发那种精致大片了，快手现在吃这套土味"

## 钩子自检
- 能不能在 3 秒内让人生出"然后呢？"的冲动？
- 有没有具体的人 / 场景 / 数字？
- 有没有站队或冲突？
- 有没有踩违禁词（见 `banned-words.md`）？
